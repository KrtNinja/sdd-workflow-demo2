## Порядок работ
001 → 002 → 003 → дальше параллельно 004, 005, 006, 007 → 008 → 009.

## Пересечения
- 003, 004, 008 трогают карточку и диалог передачи: 003 — успешный путь и валидация причины,
  004 — показ отказов сервера, 008 — реакция на сообщения сокета и отказ при сохранении.
- 006 и 007 добавляют публикацию событий в одну операцию передачи tasks-core. Механизм
  гарантированной публикации выбирается в ADR до старта обоих.
- 009 может схлопнуться, если ADR о доставке даёт порядок по задаче для обоих событий.
