# 002 — Поиск получателя

Тип: поведение
Основание: FR-2, NFR-2
Зависимости: 001
Половины: backend (tasks-core) + frontend, принимаются вместе
Результат: исполнитель в диалоге передачи находит получателя по имени

## Контракты
- contracts/tasks-core.openapi.yaml — поиск получателя (не меняется)
- tasks-core: application/ports/ProjectMembers.ts — не меняется

## Fixtures для приёмки (сверх 001)
Проект «Мобильное приложение», дополнительно:
| Кто | Сколько | Статус |
|---|---|---|
| Активные участники с «Ан» в имени (Андрей 1…Андрей 34) | 34 | активны |
| Анатолий Блоков | 1 | заблокирован |
| Анфиса Рыбина (участник проекта «Веб-кабинет») | 1 | активна |

Вместе с Анной активных совпадений по «Ан» — 35. Заблокированный и чужой участник подобраны так,
чтобы реализация, которая режет до 20 до фильтрации, провалила тест.

## Общая приёмка (собранное приложение)
AC-002-1 Найти получателя
  WHEN Анна открыла диалог передачи TASK-42
   AND ввела «Бор»
  THEN в подсказках «Борис Иванов, разработчик»

## Backend-половина
AC-002-B1 Короткий запрос
  WHEN поиск по TASK-42 с запросом «Б»
  THEN пустой результат

AC-002-B2 Лимит после фильтрации
  WHEN поиск по TASK-42 с запросом «Ан»
  THEN 20 результатов, все активные участники проекта «Мобильное приложение»
   AND среди них нет Анатолия Блокова и Анфисы Рыбиной

AC-002-B3 Неактивные и чужие
  WHEN поиск «Гле» и «Дин»
  THEN оба результата пустые

AC-002-B4 Состав данных
  WHEN поиск «Бор»
  THEN у кандидата есть только идентификатор, имя и должность

AC-002-B5 Сам пользователь
  WHEN Анна ищет «Анна»
  THEN Анна Петрова есть в результатах

AC-002-B6 Скорость
  WHEN проект из 500 участников, поиск с запросом из 2+ символов
  THEN p95 ≤ 300 мс

## Frontend-половина
AC-002-F1 Порог
  WHEN в поле поиска 1 символ
  THEN подсказок нет, запрос не отправляется

AC-002-F2 Отображение
  WHEN API вернул кандидатов
  THEN каждая подсказка показывает имя и должность, порядок как у сервера

AC-002-F3 Пусто
  WHEN API вернул пустой результат
  THEN показано «Никого не найдено»

## Границы
Вне slice: кнопка «Передать», причина и отправка (003). Сам пользователь в списке есть,
отказ при выборе себя — 004.

## Открытые вопросы к Dev Spec
- Поиск по имени и фамилии или только по имени? По началу слова или по любой подстроке? («Ива» находит Бориса Иванова?)
- В каком порядке 20 из 35 совпадений?
- Что видит пользователь, если данные об участниках недоступны во время поиска?
- Может ли искать кандидатов кто-то кроме исполнителя задачи (например, руководитель, у которого кнопки нет)?
- Нужна ли задержка ввода перед запросом и сколько?
