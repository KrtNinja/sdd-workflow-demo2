# 004 — Отказы передачи

Тип: поведение
Основание: FR-5, FR-7
Зависимости: 003
Половины: backend (tasks-core) + frontend, принимаются вместе
Результат: при невозможной передаче пользователь видит понятную причину, задача не меняется

## Контракты
- contracts/tasks-core.openapi.yaml — ошибки передачи (не меняется)
- tasks-core: domain/errors/TaskTransferErrors.ts — TASK_CLOSED, RECIPIENT_NOT_ELIGIBLE, SELF_TRANSFER, MEMBERS_UNAVAILABLE, NOT_ASSIGNEE (не меняется)

## Общая приёмка (собранное приложение)
AC-004-1 Передача себе
  WHEN Анна в диалоге по TASK-42 выбрала себя, указала причину и подтвердила
  THEN показано «Нельзя передать задачу самому себе», исполнитель TASK-42 — Анна

AC-004-2 Повтор из другой вкладки
  WHEN у Анны TASK-42 открыта в двух вкладках
   AND Анна передала TASK-42 Борису в первой
   AND до прихода сообщения о передаче передала её Вере во второй
  THEN во второй вкладке «Вы больше не исполнитель задачи», исполнитель — Борис

## Backend-половина
AC-004-B1 Закрытая задача
  WHEN Анна передаёт TASK-50 Борису
  THEN ошибка TASK_CLOSED, исполнитель не изменился

AC-004-B2 Неподходящий получатель
  WHEN получатель Глеб (заблокирован) или Дина (другой проект)
  THEN ошибка RECIPIENT_NOT_ELIGIBLE, исполнитель не изменился

AC-004-B3 Себе
  WHEN Анна передаёт TASK-42 Анне
  THEN ошибка SELF_TRANSFER

AC-004-B4 Повтор
  WHEN после успешной передачи TASK-42 Борису приходит тот же запрос от Анны
  THEN ошибка NOT_ASSIGNEE, исполнитель — Борис

AC-004-B5 Данные об участниках недоступны
  WHEN участники проекта не могут быть получены
  THEN ошибка MEMBERS_UNAVAILABLE, исполнитель не изменился

## Frontend-половина
AC-004-F1 Тексты отказов
  WHEN API вернул ошибку
  THEN показан текст:
       NOT_ASSIGNEE → «Вы больше не исполнитель задачи»
       TASK_CLOSED → «Задача закрыта»
       RECIPIENT_NOT_ELIGIBLE → «Этому пользователю нельзя передать задачу»
       SELF_TRANSFER → «Нельзя передать задачу самому себе»
       MEMBERS_UNAVAILABLE → «Передача временно невозможна, попробуйте позже»

AC-004-F2 Что дальше с карточкой
  WHEN API вернул NOT_ASSIGNEE или TASK_CLOSED
  THEN карточка закрывается, пользователь в «Моих задачах» с текстом отказа
  WHEN API вернул RECIPIENT_NOT_ELIGIBLE, SELF_TRANSFER или MEMBERS_UNAVAILABLE
  THEN диалог остаётся открытым с введёнными данными

## Границы
Вне slice: успешный путь и INVALID_REASON (003). Закрытие диалога по событию закрытия задачи
до отправки (008).
