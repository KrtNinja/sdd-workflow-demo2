# 008 — Карточка закрывается, когда задача ушла

Тип: поведение
Основание: FR-9 (прежний исполнитель), FR-10, FR-11 (клиентская часть)
Зависимости: 004, 005, 007
Половины: только frontend
Результат: у прежнего исполнителя на всех вкладках переданная или закрытая задача исчезает с понятным сообщением

## Контракты
- contracts/socket/task-transferred.message.json — не меняется
- сообщение о закрытии задачи (существующее) — не меняется
- contracts/tasks-core.openapi.yaml — отказ при сохранении (не меняется)

## Общая приёмка (собранное приложение)
```
AC-008-1 Вторая вкладка
  WHEN у Анны на ноутбуке открыта TASK-42 с недописанным комментарием
   AND Анна передала TASK-42 Борису с телефона
  THEN на ноутбуке карточка закрылась, показано «Задача TASK-42 передана: Борис Иванов»
   AND TASK-42 нет в «Моих задачах» на ноутбуке
```

```
AC-008-2 Сохранение раньше сообщения
  WHEN сообщение о передаче до ноутбука ещё не дошло
   AND Анна нажала «Сохранить» в TASK-42
  THEN карточка закрылась, показано «Задача TASK-42 передана другому исполнителю»
   AND TASK-42 нет в «Моих задачах» на ноутбуке
```

```
AC-008-3 Закрыли во время диалога
  WHEN у Анны открыт диалог передачи TASK-42
   AND Вера закрыла TASK-42
  THEN карточка и диалог исчезли без перезагрузки
```

## Frontend-половина
```
AC-008-F1 Сообщение о передаче для прежнего исполнителя
  WHEN пришло сообщение, где пользователь — прежний исполнитель
  THEN задача удалена из «Моих задач»; если её карточка открыта — она закрывается,
       несохранённые правки не сохраняются, показано «Задача <номер> передана: <имя>»
```

```
AC-008-F2 Отказ при сохранении
  WHEN API на сохранение вернул TASK_TRANSFERRED
  THEN задача удалена из «Моих задач», карточка закрывается,
       показано «Задача <номер> передана другому исполнителю»
  WHEN API на сохранение вернул общий отказ в доступе
  THEN текста о передаче нет
```

```
AC-008-F3 Закрытие с открытым диалогом
  WHEN пришло сообщение о закрытии задачи, по которой открыт диалог передачи
  THEN диалог и карточка закрываются, показано то же сообщение, что при закрытии
       открытой карточки без диалога
```

```
AC-008-F5 Сообщение после отказа при сохранении
  WHEN после TASK_TRANSFERRED по задаче пришло сообщение о её передаче
  THEN нового сообщения пользователю нет
```

```
AC-008-F4 Своя вкладка
  WHEN передача сделана в этой же вкладке
  THEN повторного сообщения поверх AC-003-F4 нет
```

## Границы
Вне slice: успешная передача в текущей вкладке (003), серверный отказ при сохранении (005),
доставка сообщений (007). Конфликт с 003 и 004: все трогают карточку задачи — 008 добавляет
только обработчики сообщений и отказа при сохранении.
